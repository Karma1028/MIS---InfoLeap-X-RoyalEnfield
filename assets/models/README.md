# Model product images

Drop RE model product photos here, named by slugified model label
(lowercase, spaces/punctuation -> underscore), e.g.:

- `royal_enfield_bullet_350.jpg`
- `royal_enfield_classic_350.jpg`
- `royal_enfield_continental_gt_650.jpg`

Matches every key in `RE_MODEL_LABELS` (utils/data_engine.py). Any model
without a matching file here just shows no image — not an error.
